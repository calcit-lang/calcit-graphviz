# Release 0.0.6 / 发布 0.0.6

- Releases Triadica as a pure Calcit DOT generator and retires the nonfunctional native stub.
- 将 Triadica 作为纯 Calcit DOT 生成器发布，并退役未实现的 native stub。
- Fixes Option-aware map-pair rendering and requires Calcit 0.13.52 with `calcit.std` 0.2.20.
- 修复基于 Option 的 map pair 渲染，并要求 Calcit 0.13.52 与 `calcit.std` 0.2.20。
